Public Nav — Which approach?

Home page + all public pages (/avis, /businesses, /r/[slug]) currently have inconsistent headers. Pick a direction.

A — Shared sticky header

One shared <PublicHeader> component used on all public pages. Nav: Logo + Annuaire + Connexion + CTA. Breadcrumb shown on inner pages. Consistent across all routes.

Grade
Comment ça marche Annuaire Tarifs Connexion Essai gratuit
Inner pages: same full nav, no breadcrumb — user uses back button or in-page links

B — Full marketing nav everywhere

Full nav with marketing links on every page. Adds "Comment ça marche" anchor and "Tarifs" anchor that scroll the home page sections. More links = more surface area, slightly heavier.

Grade
Annuaire Connexion Essai gratuit

C — Minimal nav + prominent breadcrumb bar

Lean nav (Logo + Annuaire + Auth). Dedicated breadcrumb bar below the nav on all inner pages. Clean separation of "where to go" vs "where you are". Best for SEO directory pages.

Current problems this fixes

  • ❌ 6 different inline <header> blocks — duplicated code, inconsistent
  • ❌ Login page has no back-to-home link
